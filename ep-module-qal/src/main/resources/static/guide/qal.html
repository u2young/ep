质量管理 · 使用指南

检验标准 · 质检单 · 不合格品 · 客户反馈，质量闭环一条线

它能做什么

面向质量工程师、IQC/OQC 与客服的 质量管理系统。先建「质检参数标准」定义每类物料的检验项目与合格阈值；来料（IQC）/ 过程（IPQC）/ 出货（OQC）按标准开「质检单」抽检；不合格的走「不合格品处理」（让步/返工/报废）；客户投诉/反馈在「客户反馈」里登记，处置结果回写，形成质量闭环。

菜单功能说明

菜单用途
质检参数标准检验标准：检验项目（外观/尺寸/性能）+ 合格阈值 + 抽检比例，IQC/IPQC/OQC 都引用它
质检单按检验类型（来料/过程/出货）开单，记录抽检数、合格数、不合格数与判定结果
不合格品处理不合格品的处置单：让步接收 / 供应商返工 / 报废，处置结果回写质检单
客户反馈客户投诉/质量反馈登记，关联到质检单与不合格品单，跟踪闭环

快速上手

  1. 定标准：质量工程师在「质检参数标准」里建每类物料的检验项与合格阈值
  2. 开质检：IQC/OQC 按标准开「质检单」抽检，记录抽检数/合格数/判定
  3. 开不合格：不合格的批次开「不合格品处理」单，选让步/返工/报废
  4. 跟踪处置：返工单跟到供应商/车间，处置完回填结果，质检单闭环
  5. 客户反馈：投诉在「客户反馈」里登记，关联到对应质检单与批次
  6. 复盘：按批次/供应商/缺陷类型出质量月报，驱动持续改进

场景示例：某批次来料 IQC 抽检发现 2 件划痕

电子厂 IQC 小陈负责来料检验。9 月 5 日，供应商 A 的 PCB 板批次 BA-2024-0905 到货 500 件，按「质检参数标准」（PCB 板：外观抽检 10%、尺寸抽检 5%、功能抽检 2%）抽检 50 件。

发现划痕：外观抽检 50 件中发现 2 件划痕（位于边缘，不影响焊接但影响外观），尺寸抽检 25 件全部合格，功能抽检 10 件全部合格。小陈开「IQC 质检单」，判定「部分不合格」——2 件划痕品单独隔离，48 件合格放行。

开不合格品单：小陈开「不合格品处理」单，选「供应商返工」，备注「2 件划痕品退回 A 厂，要求 3 天内打磨抛光后回厂复验」，A 厂确认接单。

复验放行：9 月 8 日 2 件返工品到货，小陈按同一「质检参数标准」复验，2 件全部合格，开「复验质检单」，处置结果回写「不合格品单」为「已返工放行」，批次 BA-2024-0905 全部 500 件入库。

客户反馈：10 月，客户 B 投诉「同型号产品 1 件外壳划痕」，客服小赵在「客户反馈」里登记，关联到 PCB 板批次 BA-2024-0905 与该型号产品，质量工程师复盘发现划痕是「抛光工序打磨不足」导致，更新「质检参数标准」中「外观」项的合格阈值（增加「抛光后复验」节点），防止再次发生。

对应菜单路径：质检参数标准(PCB 板：外观/尺寸/功能) → IQC质检单(50 件抽检发现 2 件划痕) → 不合格品处理(供应商返工) → 复验质检单(合格放行) → 客户反馈(投诉关联批次+复盘标准)

数据生命周期

① 质检主线：标准 → 单 → 判定

质检参数标准引用 → IQC/IPQC/OQC质检单— 抽检 → 判定(合格/部分不合格/不合格)
质检单必须挂「质检参数标准」：检验项、阈值、抽检比例全从标准继承，单本身只记录「实测值」，不记「标准值」（避免改标准时历史单失真）

② 不合格品主线：处置 → 闭环

质检单(部分不合格)开单 → 不合格品处理(让步/返工/报废)— 回填 → 质检单闭环(放行/报废)
让步需客户/质量总监双审批留痕；返工跟到供应商/车间，复验合格才能放行；报废需走「报废审批」，资产减值入账

③ 客户反馈：闭环的「最后一环」

客户反馈(投诉/建议)关联 → 质检单 + 批次复盘 → 质检参数标准(更新阈值)
客户反馈必须关联到具体批次/质检单，复盘后更新「质检参数标准」或工艺参数，形成「投诉→标准」的闭环；投诉未闭环的批次不能再次出货

④ 风险点与收口

质检单(判定)→ 不合格品未处置/返工未复验→ 批次放行/报废收口
风险点：不合格品未开处置单 = 批次「悬挂」，库存账实不符；返工未复验就放行 = 质量失控；报废未走审批 = 资产减值失真

使用提示

  • 标准先行先建「质检参数标准」再开质检单，无标准的物料不能进 IQC/OQC，标准是质量判定的唯一依据
  • 抽检留痕质检单必须记录「抽检数 + 实测值 + 判定」，实测值拍照/打点留档，复验时可比对
  • 处置闭环「让步/返工/报废」三选一，让步需双审批，返工必须复验合格才能放行，报废必须走审批并减值入账
  • 投诉关联客户反馈必须关联到具体批次/质检单，未关联的投诉视为「未闭环」，对应批次冻结出货
