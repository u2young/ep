落地页模块 · 使用指南

营销落地页全流程管理：amis 可视化建页 → 发布短链 → 访客留资 → 数据回流分析

它能做什么

面向运营人员的 营销落地页工作台。无需写代码，通过 amis 可视化编辑器拖拽搭建活动页/留资页，发布后自动生成短链接，访客通过短链/直链打开 H5 页面提交表单，留资数据与访问统计自动回流到本后台。

菜单功能说明

菜单用途
落地页核心功能。管理页面状态机（草稿 → 已发布 → 已下线），发布自动生成 6 位短码；记录 PV / UV 访问统计
落地页模板预设页面模板（空白 / 留资 / 产品 / 海报 / 活动），新建落地页时可快速套用
秒杀活动配置限时秒杀活动，含开始结束时间与库存，页面内自动渲染倒计时
优惠券模板定义优惠券面额、适用范围与库存，供页面领取
留资记录访客提交的表单数据：手机号、来源渠道（短链 / 直链 / 二维码）、扩展字段
秒杀订单用户抢购秒杀活动产生的订单记录
用户优惠券用户领取到的优惠券实例与使用状态
访问日志页面访问明细，按「页面 + IP + 指纹」唯一去重，支撑 UV 统计

快速上手

  1. 建模板（可选）：在「落地页模板」中预设常用页面结构，或直接跳过
  2. 建页面：在「落地页」新建页面，填写 slug（直链标识）与名称，保存为草稿
  3. 可视化编辑：进入 amis 编辑器拖拽搭建页面（表单、秒杀、优惠券组件），保存后回到列表
  4. 发布：点击「发布」按钮，系统生成 6 位短码，页面可被访问
  5. 推广：把短链 /l/{短码} 或直链 /p/{slug} 投放到广告/二维码
  6. 看数据：在「留资记录」查看线索，在落地页列表查看 PV / UV

场景示例：奶茶品牌新品上市战役

「茶语」奶茶要推秋季新品「桂花乌龙」，运营小美接到任务：两周内收集 500 条试饮预约，并搞一波限时优惠。

第 1 天：小美在「落地页」新建页面 guihua-2026，从模板库套了「留资页」模板，进设计器拖入产品图轮播 + 表单（手机号 + 门店偏好）+ 倒计时秒杀组件，保存草稿。

第 2 天：点「发布」，生成短码。电梯广告二维码指向短链 /l/A3fK9q，朋友圈广告投直链 /p/guihua-2026——两条渠道分开投放，方便对比效果。

第 5 天：配置了「周五晚 8 点 1 元券秒杀」和满 30 减 5 的优惠券模板挂到页面上。当晚 200 张秒杀券 3 分钟抢完，后台「秒杀订单」实时刷屏。

第 14 天：活动收官。小美看后台数据：PV 8600、UV 5100，「留资记录」导出 632 条——其中电梯渠道 411 条、朋友圈 221 条，下一期投放预算立刻有了依据。随后点「下线」，短链提示活动结束，但已投出的二维码依然有效（返回 410 而非 404）。

对应菜单路径：落地页(建页/发布) → 页面设计器(拖拽) → 秒杀活动/优惠券模板(配置) → 留资记录/访问日志(看效果) → 秒杀订单/用户优惠券(查明细)

数据生命周期

① 页面资产的产生与发布（核心状态机）

落地页模板套用/引用 → 草稿(0)— 「发布」→ 已发布(10) + 生成短码— 「下线」→ 已下线(20) · 短链返回410— 「重新发布」→ 已发布(复用原短码)
发布/下线通过行按钮触发，状态机约束：只有草稿和已下线状态可发布；重新发布复用短码，已投递的短链永不变更

② 访客数据的生产链路（发布之后自动发生）

访客打开 /l/{短码} 或 /p/{slug}→ 访问日志(PV / UV去重)＋ 提交表单→ 留资记录(手机号+来源渠道)
页面内互动→ 秒杀订单＋ 用户优惠券(模板→领取→使用)
UV 按「页面 + IP + 指纹」唯一去重；留资/订单/领券均由 C 端公开 API 产生，运营只在后台查看，不手工录入

③ 数据关联与终点

模板1 → N落地页1 → N 访问日志 / 留资 / 秒杀订单 / 用户优惠券
终点规则：删除均为逻辑删除（数据保留可恢复）；访问日志与留资为业务凭证只增不改；页面删除不影响已产生的留资数据

使用提示

  • 状态机发布按钮仅在草稿 / 已下线状态下可用；下线后短链返回 410，重新发布复用原短码
  • 免登访问C 端页面（/p/{slug}、/l/{code}）与留资接口无需登录，管理后台数据需登录查看
  • UV 去重同一访客（IP + UA 指纹）对同一页面重复访问只计一次 UV
  • 接口留资/秒杀/领券均为公开 API（/api/landing/*），便于对接小程序或第三方投放
