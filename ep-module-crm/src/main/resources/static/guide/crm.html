CRM客户管理 · 使用指南

围绕销售漏斗展开：线索 → 客户 → 商机 → 合同 → 回款，每一步都更接近成交

它能做什么

面向销售团队与销售管理者的 客户关系管理系统。管理从模糊线索到确定交易的全过程：销售录入线索并跟进，转化成客户后创建商机推进阶段，赢单后签订合同、按计划回款。支持客户公海自动回收、团队协作与跟进留痕。

菜单功能说明

菜单用途
客户客户档案管理：跟进状态、成交标记、锁定；负责人为空即进入公海
联系人客户下的关键联系人，可标记决策人，支持层级关系
线索模糊销售信息入口：录入 → 分配 → 跟进 → 转化为客户
商机成交机会管理，按阶段推进（阶段可配置），支持赢单 / 输单 / 无效结束
商机状态类型 / 商机状态可配置的阶段流：状态组下定义各阶段名称、赢单率与排序
合同与客户签订的合同，登记金额与期限，关联回款
回款计划 / 回款记录按期数规划回款（可设提前提醒天数），实际回款逐笔登记
跟进记录通用于线索/客户/商机/合同的跟进流水（拜访、电话、纪要）
团队成员商机/合同等对象的协作成员与权限（读写）
客户公海配置公海规则：未跟进 N 天 / 未成交 N 天自动掉入公海，认领上限

快速上手

  1. 配基础：管理员先配置「商机状态类型」阶段流与「客户公海配置」规则
  2. 录线索：销售把展会名单、广告询盘录入「线索」，持续跟进
  3. 转客户：意向明确的线索执行「转化」，生成客户与联系人
  4. 推商机：为有采购意向的客户创建商机，随推进更新阶段（赢单率上升）
  5. 签合同：赢单后录入合同金额与期限
  6. 收回款：按「回款计划」登记每笔回款，系统校验累计回款不超合同金额

场景示例：销售小王的 38 万大单

小王是收银系统公司的销售。3 月的行业展会上，他扫了 40 多张名片，全部录入「线索」。

线索期：其中一条是「 chain 餐饮集团 王经理，30 家连锁店想升级收银」。小王打电话跟进了 2 次，判断预算充足——点「转化」，系统自动生成客户「chain 餐饮集团」和联系人「王经理（决策人）」。

商机期：创建商机「50 门店收银系统采购」，挂在客户下，选用默认阶段流。之后 6 周里他不断推进阶段：初步接触 → 需求确认(40%) → 方案报价(60%) → 商务谈判(80%)，每次电话拜访都写跟进记录。拉了技术顾问小陈进「团队成员」一起做方案。

插曲：5 月小王去外地支援别的项目，21 天没动这条客户——系统定时任务按「未跟进超 15 天」规则把它掉进了公海。同事小李认领了它。小王回来跟小李协商，领导仲裁后小李把客户转让回小王。从那以后他养成了每天写跟进记录的习惯。

成交：6 月赢单，签订 38 万合同（软件 30 万 + 硬件 8 万），回款计划分 3 期：签约 50%、上线 30%、验收 20%。到 9 月，三期回款记录全部登记完成，客户标记「已成交」。

对应菜单路径：线索(录入/跟进/转化) → 客户+联系人(转化生成) → 商机(阶段推进/团队成员) → 合同(签订) → 回款计划+回款记录(分期回款) —— 全程跟进记录贯穿

数据生命周期

① 销售漏斗主线：一条数据的完整旅程

线索(录入/分配)— 跟进·转化 → 客户 + 联系人创建 → 商机(阶段推进)— 赢单 → 合同规划 → 回款计划— 逐期登记 → 回款记录(结清)
「转化」把线索升级为客户+联系人，线索本身转为已转化终态；每条数据的 owner（负责人）字段贯穿全程，决定数据可见性

② 关键状态机

线索： 未处理→跟进中 →已转化 /无效
商机： 按阶段推进(阶段可配置) →赢单 /输单 /无效
回款计划： 未收款— 登记回款记录 →已收款(累计不得超合同金额)
商机阶段流由「商机状态类型 → 商机状态」配置驱动（各阶段赢单率可设）；阶段推进、赢单/输单/无效均为行按钮操作

③ 公海循环：客户资源的流转池

销售私海(有负责人)— 超期未跟进/未成交 · 定时任务回收 → 公海(负责人为空)— 他人「认领」→ 新负责人私海
回收规则由「客户公海配置」驱动：未跟进 N 天 / 未成交 N 天自动掉公海，每人有认领上限；跟进记录的最近时间是回收判定依据

④ 数据关联与终点

客户1 → N联系人 / 商机 / 合同 　合同1 → N回款计划 / 回款记录 　跟进记录(挂线索/客户/商机/合同)
终点规则：所有实体逻辑删除；线索以转化/无效收口；商机以赢单/输单/无效收口；回款累计校验不可超合同金额，数据闭环完整

使用提示

  • 公海回收超过「客户公海配置」设定天数未跟进/未成交的客户会被定时任务自动掉入公海，供他人认领，防止销售囤客户
  • 商机结束商机只能以赢单 / 输单 / 无效三种方式结束，赢单后建议立即创建合同
  • 回款校验回款记录累计金额不可超过合同金额，录入时系统自动校验
  • 跟进留痕每次接触客户后务必写「跟进记录」，它同时是公海回收天数的判定依据
