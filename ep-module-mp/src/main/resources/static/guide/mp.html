微信公众号 · 使用指南

微信生态在本地数据库的投影：粉丝、消息、素材、菜单、自动回复全量留存与可视化运营

它能做什么

面向新媒体运营的 公众号运营后台。把分散在微信服务器上的运营资源（粉丝、消息、素材、菜单、标签、自动回复）同步到本地数据库，补齐微信原生短板：消息留存超过 3 天、自定义业务路由、统计二次加工。支持多公众号账号管理。

菜单功能说明

菜单用途
公众号账号接入入口：配置 appid / secret / token / aeskey，一个账号一套凭证；其余菜单数据都归属账号
微信菜单本地编辑公众号底部菜单（一级最多 3 个、二级 5 个），编辑后同步发布到微信
自动回复三类回复规则：关注回复、消息回复、关键字回复（匹配模式支持包含 / 相等）
素材图文 / 图片 / 语音 / 视频素材库，上传后可被菜单、自动回复、群发引用
消息粉丝消息全量留痕（微信只保留 3 天，这里永久留存），支持客服消息回复（粉丝 48h 内有交互时）
用户粉丝列表：关注/取关自动同步、备注、打标签
用户标签粉丝分组标签（每号上限 100 个），可批量为粉丝打标签

快速上手

  1. 接入账号：在「公众号账号」录入 appid / secret 等凭证，保存后系统自动管理 access_token（7200s 自动续期）
  2. 同步粉丝：在「用户」点击同步，拉取粉丝列表；按需建「用户标签」分组
  3. 配回复：在「自动回复」配置关注自动欢迎语与关键字回复
  4. 发菜单：在「微信菜单」搭建底部菜单结构，点击发布同步到微信
  5. 传素材：在「素材」上传图文/图片素材，供后续群发与回复引用
  6. 看消息：粉丝互动消息在「消息」中永久可查，可及时客服回复

场景示例：独立书店的公众号运营

「青柠书屋」是一家独立书店，公众号有 1.2 万粉丝。运营小陈接手后第一件事：把公众号接到本系统。

接入：在「公众号账号」填入 appid / secret，菜单同步拉取到全部粉丝。「用户」里 1.2 万条粉丝记录（昵称、头像、关注时间），小陈建了「活跃读者」「购书群成员」两个标签，把常互动的 800 人打上标签。

自动回复：「自动回复」里配了两条——关注回复：欢迎语 + 新客 9 折码；关键字回复：粉丝发送“书单”自动推送当月书单图文。当晚就有 37 个新关注领了 9 折码。

菜单与素材：小陈在「微信菜单」搭了三个一级菜单（新书速递 / 每月书单 / 到店指引），「素材」上传了 6 篇图文，点「发布」同步到微信——三分钟搞定，不用碰微信公众平台后台。

一个月后：粉丝留言“上次的咖啡书会照片还有吗？”——微信后台已经查不到这条 5 天前的消息，但小陈在系统「消息」里秒搜到原文并回复了她。月底看数据：取关的 63 人记录也都在，取关时间集中在涨价周——结论出来了。

对应菜单路径：公众号账号(接入) → 用户+用户标签(粉丝运营) → 自动回复(欢迎语/关键字) → 素材(图文库) → 微信菜单(发布) → 消息(永久留痕+客服回复)

数据生命周期

① 粉丝生命周期：关注 / 取关循环

微信侧关注事件回调 → 用户记录(已关注·同步资料)— 打标签 → 用户标签分组
已关注— 取关事件 → 已取关(记录保留·更新时间留痕)— 再次关注 → 已关注(同一条记录复用)
粉丝数据由微信回调自动产生和更新，不需要也不应该手工录入；支持手动同步全量粉丝列表

② 消息生命周期：3 天 → 永久

粉丝发消息回调 → 消息入库(永久留存)→ 命中规则? → 自动回复(关注/消息/关键字)
消息入库— 运营在 48h 交互窗口内 → 客服消息回复超时 → 仅留档不可回复
微信服务器只保留 3 天消息，本系统永久留痕——这是消息数据最大的价值；自动回复按开关与匹配模式（包含/相等）实时判定

③ 运营资产：菜单与素材

微信菜单：本地编辑— 发布同步 →已上线个性化菜单只能删除重建 →重建
素材：本地上传→ 被引用 →菜单 / 自动回复 / 群发本地留存 →长期保留
access_token 由系统集中管理（7200s 自动续期），所有微信 API 调用凭它进行，凭证失效是大多数接口报错的根因

④ 数据关联与终点

公众号账号1 → N粉丝 / 消息 / 素材 / 菜单 / 自动回复 / 标签 　粉丝N ↔ N标签
终点规则：账号为归属根节点，删除账号不影响历史数据但停止同步；粉丝取关记录保留；消息与素材永久留存

使用提示

  • 服务器配置微信公众号后台需将服务器 URL 指向本系统回调地址并启用，消息才会推送进来
  • 个性化菜单微信限制：个性化菜单不可编辑，只能删除重建；发布前先在本地核对结构
  • 客服消息仅当粉丝 48 小时内有交互时才能主动发客服消息
  • token 自动续期access_token 由系统集中管理并自动刷新，无需人工干预
