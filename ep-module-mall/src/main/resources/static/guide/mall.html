商城管理 · 使用指南

商品中心 + 交易中心 + 支付：从上架成交到售后的电商全链路

它能做什么

面向电商运营的 商城管理后台，覆盖商品中心（SPU/SKU、分类、品牌）、交易中心（订单、售后）与支付中心（支付单）。管理商品上架与规格库存，跟进订单履约（发货/收货），处理退款退货售后流程。

菜单功能说明

菜单用途
商品 SPU商品主档：名称、卖点、详情、上下架状态；一个 SPU 挂多个 SKU
商品 SKU规格组合实例（如 红色/XL）：各自的价格、库存、条码
商品分类商品类目树，商城前台导航的数据来源
商品品牌品牌档案：品牌名、图标、状态
交易订单订单主表：状态流转（待付款 → 待发货 → 待收货 → 已完成）、收货地址、金额
订单明细订单商品行快照：下单时的商品名、价格、数量（不受后续改价影响）
售后单退款/退货申请：类型、原因、凭证，走同意 → 买家寄回 → 收货 → 退款完成流程
售后日志售后单每次状态变更的操作留痕
支付单订单的支付/退款流水，记录支付渠道与回调状态

快速上手

  1. 建基础：先维护「商品分类」与「商品品牌」
  2. 上商品：创建 SPU 填写基础信息与详情，再为它生成 SKU 组合并定价、填库存，最后上架
  3. 接订单：买家下单支付后，订单进入「待发货」，在「交易订单」执行发货
  4. 履约：买家确认收货（或超时自动确认）后订单「已完成」，货款按「支付单」对账
  5. 处理售后：买家申请后按流程操作——同意 → 收到退货 → 完成退款，每步自动记入售后日志

场景示例：一件羽绒服的订单旅程

上货：运营小周建了 SPU「极寒系列羽绒服 90 白鸭绒」，生成 SKU 黑色 / XL（库存 50 · 售价 899），上架。同一天，买家小张下了单。

下单：小张提交订单 899 元——订单状态「待付款」，库存 50 → 锁定 1。他犹豫了 20 分钟才付款，没超过 30 分钟支付超时线。支付回调后状态「待发货」，库存真扣 → 49 · 销量 +1，支付单记录微信支付 899 元成功。

履约：次日仓库点了「发货」，填顺丰单号，状态「待收货」。第 5 天小张确认收货，订单「已完成」，自动加了 89 积分。

售后：第 7 天小张发现拉链卡顿，在订单里对这件商品发起退货退款（售后针对订单项，同单里买的围巾不受影响）。商家点「同意」，小张寄回填单号，商家收货验货通过，「退款成功」——899 元原路退回微信，SKU 库存回滚 +1（恢复 50）。全程 4 步操作，「售后日志」里每一步谁在什么时间点的都有记录。

过程中商品改价：期间小周把 XL 提价到 999——但小张的订单明细仍显示 899，订单快照不受改价影响，售后退款也按快照 899 执行。

对应菜单路径：商品SPU/SKU(上架·改价) → 交易订单+订单明细(下单→发货→完成) → 支付单(收款/退款流水) → 售后单+售后日志(退货退款闭环)

数据生命周期

① 商品资产：SPU → SKU 的组织方式

分类树 + 品牌挂靠 → 商品SPU(主档·详情)— 规格组合 → 商品SKU(价格·库存·条码)— 上架 → 可售
SPU 上下架控制前台可见性；SKU 是库存与订单结算的最小单位

② 订单状态机（核心）：每一步的触发与副作用

待付款(0)— 支付回调 → 待发货(10)— 商家发货 → 待收货(20)— 确认/超时自动 → 已完成(30)
取消出口： 待付款— 用户取消/支付超时(15-30min) →已取消(40)·释放锁定库存·返还券和积分
下单锁定库存 → 支付真扣库存并累加销量 → 取消释放库存 → 完成触发分销返佣与积分；订单明细是下单时刻的商品快照，改价不影响历史订单

③ 售后状态机：按订单项粒度发起

申请退款(10)仅退款 → 商家同意(20)— 打款 → 退款成功(60)
申请退款(10)退货退款(type=2) → 同意退货(20)买家寄回 → 买家已发货(30)签收验货 → 商家已收货(40)验货通过 → 退款成功(60)
其他出口： 任意阶段→ 买家取消(80)/ 管理员关闭(70)
售后针对订单项（order_item）而非整单，同一订单不同商品可分别售后；退款成功回调库存回滚（调 erp changeStock）；每步自动写「售后日志」

④ 支付单与数据终点

支付单：待支付— 回调 →支付成功售后退款 →已退款(原路退回)
终点规则：订单不可物理删除（财务凭证）；售后完成 = 终态，售后日志完整回溯；商品逻辑删除不影响历史订单快照

使用提示

  • 快照原则订单明细保存下单时刻的商品信息，之后修改 SPU/SKU 不影响历史订单
  • 状态机订单按钮（付款 / 发货 / 取消 / 确认收货）只在对应状态下出现，防误操作
  • 售后留痕售后单的每次操作都会写「售后日志」，争议时可完整回溯
  • 库存联动下单锁库存、付款扣库存，取消订单自动回补 SKU 库存
