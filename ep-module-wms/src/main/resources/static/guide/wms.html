WMS仓储管理 · 使用指南

管的是实物：它在哪里（库位）、什么状态（四态库存）、按什么策略流转（单据状态机）

它能做什么

面向仓储作业人员的 仓库执行管理系统。区别于 ERP 的「账面库存」，WMS 管到 仓库 → 库区 → 库位 三级物理位置，库存分可用 / 锁定 / 在途 / 冻结四态。入库走「到货通知 → 收货 → 上架」状态机，出库走「发货通知 → 拣货 → 发货」链路，每一步都有单据可查。

菜单功能说明

分组菜单与用途
基础数据仓库（多仓档案）、库区（收货区/存储区/拣货区等类型）、库位（货架-层-位坐标 + ABC 分类，上架推荐的目标）
库存核心库存（SKU × 仓库 × 库位多维余额，四态数量）、库存移动（每笔增减的流水明细，只增不改）、盘点单/明细（账实核对，生成盈亏调整）
入库链路到货通知（上游预报"将要来什么"）→ 收货单（实物签收，支持分批收货）→ 上架单（系统推荐库位，实物上架确认）
出库链路发货通知（下游出库需求）→ 拣货单（按库位生成拣货任务）→ 发货完成回写通知单
库内作业移库单（库位间调拨，主表 + 明细），执行后同步更新库位库存

快速上手

  1. 建仓：先建「仓库」，再在仓库下建「库区」，最后建「库位」（编码如 A-01-02 表示 货架-排-层）
  2. 入库：收到采购预报后录「到货通知」→ 货到执行「收货」（可多次）→ 生成「上架单」按推荐库位上架 → 库存增加
  3. 出库：下游推送「发货通知」→ 按库存分配生成「拣货单」→ 仓员按库位拣货 → 执行发货，库存扣减
  4. 库内：库位调整用「移库单」；定期用「盘点单」核对账实，差异生成调整

场景示例：1000 箱矿泉水的仓储之旅

「惠民超市」的中心仓收到采购部预报：1000 箱矿泉水周二入库。仓管老李一周的操作如下：

周二上午：老李在「到货通知」录入 ASN（品名、数量 1000、预计到达）。周三货车到，第一车 600 箱——建「收货单」先收 600 箱（分批收货），周四第二车 400 箱到齐后完成收货。系统提示上架库位 A-03-01（A 区饮料存储位、空位充足、C 类大宗商品），老李扫码确认，两张「上架单」全部完成，A-03-01 库位可用库存 +1000。

周四下午：电商渠道要 200 箱发前置仓。「发货通知」录入后系统自动锁定 200（可用变 800，锁定 200）——防止别的订单把这些货卖掉。老李按「拣货单」提示走到 A-03-01 搬货 200 箱，点「完成拣货」并发货，库存真正扣减：可用 800 · 锁定 0。

月底盘点：A 区盘点，A-03-01 实际 797 箱，账面 800——差 3 箱（水是易损耗品）。盘点单记录差异，完成时生成盈亏调整 −3，账实一致。

次月：饮料销售旺季结束，老李用「移库单」把 A-03-01 剩余的 197 箱中的 100 箱挪到 B 区滞销位（位置变了，总数没变——移库只改库位分布）。

期间任何时候有库存疑问：打开「库存移动」，按 SKU 过滤，每一笔 +600/+400/+1000上架/−200发货/−3盘亏/移库 都清清楚楚，带来源单据号

数据生命周期

① 入库链：一票货从预告到上架

到货通知ASN(预告)— 生成 → 收货单(实物签收·可分批)— 完成收货 → 上架单(系统推荐库位)— 完成上架 → 库存(可用 +N)
每步由单据按钮推进；收货支持分批（多次收货直到完成）；上架时按库位空闲 + ABC 分类推荐库位，允许改为实际库位

② 出库链：一票货从需求到离场

发货通知(出库需求)— 分配库存(锁定) → 拣货单(按库位生成任务)— 完成拣货·发货 → 库存扣减(锁定转扣减)→ 通知单完成
出库分配即产生「锁定」库存——先占坑再扣减，防止超卖；发货完成后自动回写通知单状态

③ 库存四态：每一件货的实时身份

可用= 总量− 锁定(出库已分配)− 在途(入库未上架)− 冻结(盘点/质量问题)
库存记录维度 = SKU × 仓库 × 库位；任何数量变化必经单据按钮触发，系统同步写「库存移动」流水

④ 库内作业与数据终点

移库单：草稿→执行中(库存位置迁移)→完成
盘点单：草稿→盘点中(账实核对·冻结)→完成(差异生成盈亏调整)
终点规则：业务单据完成后不可删除（审计留痕）；「库存移动」流水只增不改，每笔含来源单据类型与单号，是库存追溯的最终依据

使用提示

  • 单据驱动所有库存变动必须通过单据按钮（完成收货 / 完成上架 / 完成拣货 / 执行移库）触发，不允许手改库存
  • 四态库存可用 = 总量 − 锁定 − 在途 − 冻结；出库分配即锁定，发货扣减
  • 上架推荐上架单自动推荐空库位（优先同库区、ABC 分类匹配），仓员可改实际库位
  • 流水追溯任何库存疑问先查「库存移动」流水，每笔含来源单据类型与单号
