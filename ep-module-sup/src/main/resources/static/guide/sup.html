服务支持管理 · 使用指南

工单 · SLA · 分派 · 知识库，服务支持一条线

它能做什么

面向客服、技术支持与 IT 运维的 服务支持系统。客户报障/咨询在「客户工单」里创建，按「工单优先级」与「SLA 服务等级协议」计算响应/解决时限；「工单分派历史」记录工单在工程师之间的流转轨迹；解决后沉淀到「知识库」，下次同类问题直接复用；「服务支持配置」控制分派策略、SLA 模板等规则。

菜单功能说明

菜单用途
工单优先级工单分级（P1-紧急/P2-高/P3-中/P4-低），SLA 响应时限按级别计算
SLA服务等级协议按客户/产品定义响应与解决时限（如 P1 客户 30 分钟响应、4 小时解决），超时告警
客户工单客户报障/咨询/投诉入口：分类、描述、附件、优先级、SLA 计时
工单分派历史工单在工程师之间的分派/转派轨迹，谁在什么时间分到什么工单，全程留痕
知识库解决方案沉淀：按问题分类，工程师处理时检索复用，客户也可自助查
服务支持配置分派策略（轮询/技能/负载）、SLA 模板、告警阈值、工单分类树

快速上手

  1. 定 SLA：管理员在「SLA 服务等级协议」里按客户/产品定响应/解决时限
  2. 定分级：「工单优先级」定 P1-P4，SLA 响应时限按级别 × 客户等级计算
  3. 建工单：客户报障 → 客服在「客户工单」里创建，系统自动挂 SLA 计时
  4. 分派：按「服务支持配置」的分派策略（轮询/技能）自动分派到工程师
  5. 解决：工程师处理，解决后写处理记录，工单关单
  6. 沉淀：典型解法录入「知识库」，下次同类问题直接复用

场景示例：企业客户报障 SLA 2 小时响应

某软件公司服务企业客户 B，B 是 P1 客户，按「SLA 服务等级协议」签约：响应 2 小时、解决 8 小时。

工单创建：9 月 10 日 14:00，B 公司 IT 管理员打客服电话报障「生产环境数据库连接池耗尽，业务全停」。客服小林在「客户工单」里建单，分类「数据库」、优先级「P1」、客户「B（P1）」，系统自动挂 SLA 计时——响应时限 16:00、解决时限 22:00。

分派处理：按「服务支持配置」的「技能分派」策略，工单自动分派给数据库工程师小吴（技能标签「数据库-MySQL」）。14:12 小吴接单，SLA 响应达成（提前 108 分钟）。小吴 1 小时内定位到「慢查询 + 连接池配置过小」，15:30 重启服务 + 调整连接池参数，业务恢复。

工单关单：小吴在工单里写处理记录（慢查询 SQL、连接池参数从 50 调到 200、重启时间），关单。系统算 SLA 达成率——响应 14:12/16:00（达成）、解决 15:30/22:00（达成），工单归档。

沉淀知识库：小吴把「数据库连接池耗尽 → 慢查询 + 连接池参数调优」的解法录入「知识库」，分类「数据库-连接池」，下次同类问题工程师可直接检索复用。B 公司 IT 管理员也能在客户门户自助查知识库，减少重复报障。

服务支持报表：月底服务支持主管老赵跑「SLA 达成率」报表——B 客户 P1 工单 12 张，SLA 达成率 91.7%，1 张 P1 工单响应超时（凌晨 3 点报障，值班工程师 35 分钟后响应），老赵把「夜间响应」加入 SLA 告警配置，避免再次超时。

对应菜单路径：SLA服务等级协议(2h响应/8h解决) → 客户工单(P1 创建+SLA 计时) → 工单分派历史(技能分派到小吴) → 工单关单(处理记录) → 知识库(解法沉淀) —— 工单优先级+服务支持配置贯穿全程

数据生命周期

① 工单主线：从创建到关单

客户工单(创建)— 分派 → 工程师处理(接单/解决)— 关单 → 工单归档
工单状态机：待分派 → 处理中 → 待客户确认 → 已关单；SLA 计时从「创建」开始，「响应达成」「解决达成」两个关键节点自动打点

② SLA 主线：响应/解决双计时

SLA服务等级协议驱动 → 客户工单(响应计时 + 解决计时)→ 超时告警(响应超时/解决超时)
SLA 按「客户等级 × 优先级」双维度计算响应/解决时限；超时前 30 分钟自动告警到工程师 + 主管，超时后工单标红、纳入 SLA 达成率报表

③ 分派历史：工单的「轨迹」

客户工单— 自动分派 → 工单分派历史(分派轨迹)— 转派/退回 → 工程师接单(闭环)
分派策略由「服务支持配置」控制：轮询/技能/负载三选一；转派必须留痕（谁、什么时间、为什么），分派历史是服务支持审计的唯一来源

④ 知识库：解法的「沉淀池」

工单关单(处理记录)沉淀 → 知识库(按问题分类)— 检索复用 → 下次同类工单(直接引用)
知识库是「工单 → 知识」的沉淀通道：典型解法录入知识库，下次同类工单工程师可直接引用，减少重复排查；客户门户可自助查，降低报障量

使用提示

  • SLA 先行签约客户必须先建「SLA 服务等级协议」再开工单，无 SLA 的工单默认按「P3 + 普通客户」计时，容易超时
  • 分派策略按「技能分派」配置工程师技能标签，避免 P1 工单分派给不熟的工程师导致响应超时
  • 处理记录关单前必须写处理记录（定位过程 + 解法），不写不能关单；记录是知识库沉淀的原料
  • 知识库复用工程师处理工单时先检索知识库，命中直接引用；未命中才走排查，排查完必须回填知识库
