ERP进销存 · 使用指南

采购 → 库存 → 销售 → 财务全链路，进销存一体、账实相符

它能做什么

面向进销存业务的 ERP 一体化系统。统一管理产品分类、品牌、单位、仓库与供应商/客户等基础档案；采购侧从采购订单到入库验收，销售侧从销售订单到出库发货，库存余额实时联动；入库自动生成应付、出库自动生成应收，再通过付款单/收款单核销，把「货、款、账」串成闭环。

菜单功能说明

菜单用途
产品分类 / 单位 / 品牌产品主数据基础档案：类目、计量单位、品牌
仓库档案仓库主数据，库存余额按「仓库 × 产品」维度挂账
供应商档案供应商基本信息、结算方式、结算账户
销售客户客户档案：信用额度、结算方式，销售订单的来源
结算账户银行/现金账户，收付款单据挂接的账户
产品档案 / 产品SKU产品主数据与规格型号（SKU），销售/采购/库存的挂接对象
库存余额按仓库、产品汇总的实时数量与金额，只读视图
其他入库单 / 其他出库单非采购/销售引起的库存变动：盘盈、调拨、报废等
采购订单 / 采购入库单向供应商下单 → 到货验收入库，入库同时增加库存并生成应付
销售订单 / 销售出库单与客户下单 → 发货出库，出库同时减少库存并生成应收
付款单 / 收款单对供应商付款、对客户收款，逐笔核销应付/应收
核销记录收付款与应收应付的核销流水，资金与债权对应关系留痕

快速上手

  1. 建档案：维护产品分类、单位、品牌、仓库、结算账户、供应商与销售客户
  2. 录产品：录入产品档案与 SKU，形成可售、可采的主数据
  3. 走采购：创建采购订单，到货后下采购入库单，库存增加、应付生成
  4. 走销售：创建销售订单，发货后下销售出库单，库存减少、应收生成
  5. 收付款：付款单核销应付、收款单核销应收，登记核销记录
  6. 对库存：随时查看库存余额，其他出入库单处理盘点与调拨差异

场景示例：某贸易公司月度采购 1000 箱矿泉水

贸易公司采购员小赵负责饮料线。月初，他向「供应商档案」里的 A 食品加工厂下达 采购订单 1000 箱（单价 12 元/箱，合同金额 12000 元）。

分批入库：供应商分 2 批到货——第 1 批 600 箱验收合格，小赵开 采购入库单；第 2 批 400 箱中有 8 箱破损，仓库按 392 箱实际入库。两张入库单过账后，「库存余额」中该 SKU 从 200 箱增至 984 箱，同时系统生成 应付 11904 元（392×12 + 600×12，破损 8 箱按采购配置扣款）。

付款核销：财务老钱在下「结算账户」里的工行账户开 付款单 11904 元，勾选对应应账户款逐笔核销，「核销记录」中该供应商欠款清零。

销售出库：B 便利店超市的月度订单到货后，仓管开 销售出库单 900 箱，库存余额降为 84 箱，同时生成 应收 10800 元。

收款回款：客户财务打款后，小赵开 收款单 核销应收，本月度进销存资金全部回正，货款两清。

对应菜单路径：供应商档案 → 采购订单 → 采购入库单(增库存+生成应付) → 库存余额 → 付款单+核销记录；销售客户 → 销售订单 → 销售出库单(减库存+生成应收) → 收款单+核销记录

数据生命周期

① 采购主线：货到、款到、账齐

供应商档案— 下单 → 采购订单— 到货验收 → 采购入库单增库存·生成应付 → 付款单— 核销 → 核销记录(应付清零)
入库单过账是库存与应付的「双生」节点：库存余额增加与应付生成在同一事务完成，保证账实同步

② 销售主线：货出、款收、账平

销售客户— 下单 → 销售订单— 发货 → 销售出库单减库存·生成应收 → 收款单— 核销 → 核销记录(应收清零)
出库前校验库存余额是否充足（可配置超卖策略）；出库与应收生成同事务，回款核销后方可关闭应收

③ 库存主线：一切出入都留痕

库存余额(仓库×产品)← 采购入库单　 销售出库单　 其他出入库单(盘盈/调拨/报废)
库存余额是只读汇总视图，任何数量变化都必须通过单据驱动；其他出入库单用于处理盘点差异与仓库间调拨

④ 档案与单据的关系

产品/SKU被引用 → 采购·销售·出入库单 　 仓库档案挂账 → 库存余额 　 结算账户挂接 → 收付款单
档案被单据引用后建议归档而非删除；收付款必须选择结算账户，核销记录把资金流与债权债务一一对应

使用提示

  • 库存校验销售出库时系统按仓库×产品校验库存余额，不足时按配置拦截或告警，避免超卖
  • 应付自动生成采购入库单过账即生成应付，无需手工记账；付款单只核销已生成的应付，金额不可超出
  • 核销留痕收付款核销后「核销记录」不可撤销，发现差错应走红冲/反冲单据，保持流水可追溯
  • 档案先行先建齐供应商、客户、仓库、结算账户等档案再下单，避免单据挂接缺失造成财务对账困难
