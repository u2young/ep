制造管理 · 使用指南

BOM · 工序 · 工作中心 · 工单 · 派工 · 委外，车间一条线

它能做什么

面向车间、计划与工艺工程师的 制造执行系统。先建「BOM 工艺清单」（产品怎么拆、用什么料）、工序与工作中心（活在哪做、谁做）；接到订单下「工单」，工单按工序「派工」到工作中心；完成一件「报工」入库；自制做不来的部分走「委外单」外包，成品/半成品库存全部可追溯。

菜单功能说明

菜单用途
工序定义工序模板（如切割、机加工、焊接、涂装、总装），含标准工时
工作中心执行车间/设备/班组，工序派工的落点
BOM工艺清单产品物料清单 + 工艺路线：拆料 + 按什么顺序在哪做
工单生产指令：按 BOM 展开数量、下达、执行、完工收口
派工单把工序「投」到工作中心：派工人、排期、报工入口
生产出入库单工单领料出库、半成品/成品入库，库存同步变动
委外单外包工序/部件：发料 → 外厂加工 → 收货入库

快速上手

  1. 建工艺：工艺工程师维护「工序定义」「工作中心」「BOM 工艺清单」
  2. 下工单：计划员按订单下「工单」，BOM 自动展开领料需求
  3. 派工：车间主任把工序「派工」到工作中心，指定班组/设备/排期
  4. 报工：工人完成工序后在「派工单」报工，系统自动开「生产入库单」
  5. 委外：自制做不来的工序走「委外单」，外厂完成后收货入库
  6. 查库存：领料、半成品、成品全部通过「生产出入库单」入账，库存可查

场景示例：1000 件成品订单生产全流程

公司接了某客户「1000 件铝合金外壳」的订单，工艺路线 5 道：下料 → 机加工 → 焊接 → 表面处理 → 总装。

BOM 展开：工艺工程师小李在「BOM 工艺清单」里确认外壳产品的工艺路线与物料清单（铝锭 3.2 kg/件 + 焊丝 0.15 kg/件 + 喷漆 0.3 L/件），下料工序需 1050 件毛坯（含 5% 损耗）。

工单下达：计划员小吴在「工单」里下 1000 件生产指令，BOM 自动展开领料需求——铝锭 3360 kg、焊丝 150 kg、喷漆 300 L，开「生产出库单」领料。

派工：车间主任老张把工序「派工」——下料机加工班组（排期 1 天）、机加工 2 号机台（排期 3 天）、焊接 1 班组（2 天）、喷涂车间（1 天）、总装 2 班组（1 天）。每个班组每天在「派工单」上 报工。

委外：焊接后 5 件不合格，老张开「委外单」把 5 件毛坯送 A 外协厂返工，3 天后收货入库，5 件补入合格品。

完工入库：1000 件外壳全部完工，开「生产入库单」入成品仓，工单状态改「完工」，整单耗时 8 天，一次合格率 99.5%。

对应菜单路径：BOM工艺清单(物料+工艺路线) → 工单(下达+展开领料) → 派工单(投到工作中心+报工) → 生产出入库单(领料/入库) → 委外单(外包补件) —— 工序定义与工作中心贯穿全程

数据生命周期

① 工艺主线：BOM → 工单 → 派工

BOM工艺清单— 下达 → 工单(展开领料)— 派工 → 派工单(投到工作中心)
工单是「量」的主线，派工单是「工序×工作中心」的执行单元；BOM 改版本不影响已下达工单，影响后续新工单

② 报工与库存：生产流水

派工单— 报工 → 生产入库单→ 半成品/成品入库
工单— 领料 → 生产出库单→ 原材料减库存
报工是「人→机器→物料」的汇聚点：报工完成才允许开生产入库单；领料必须在工单下达后，超领需审批

③ 委外主线：外包不脱链

委外单(发料)— 外厂加工 → 委外收货入库→ 并入工单/库存
委外单挂工单：发料走「委外出库单」，收货走「委外入库单」，外厂费用挂账应付；委外不中断库存流水

④ 风险点与收口

工单(下达)→ 报工漏录/超领未审批→ 完工收口(领-用-产-存闭环)
风险点：报工漏录导致库存「有账无实」；超领未审批导致 BOM 成本失真。完工后工单状态改「完工」，领-用-产-存可勾稽核对

使用提示

  • BOM 版本BOM 工艺清单建议用版本号管理，改料号/用量后旧版本保留，新工单按最新版本展开
  • 派工粒度派工按「工序×工作中心×班」三维度，不要跨工序合并派工，否则报工数据无法拆到工序
  • 委外挂工单委外单必须挂到具体工单，不挂工单的委外只能走「其他出入库」，库存对不上账
  • 超领审批超领必须走审批，留痕可查；完工后跑「领-用-产-存」勾稽报表，差异 > 2% 触发工艺复核
